# Design System: Droolbites

## Overview

**Creative North Star: "The Bakery Counter Paper"**

Droolbites is a small bakery printed on warm paper: cream background, ink-green text, one deep moss that does all the structural work, and a handful of confectionery accents (mustard, lavender, salmon, mint) that show up only as product tints, status dots and sticker-like moments. The storefront is generous and photographic. The admin is the same material, calmer and denser, with the moss moved from accent to a full-height sidebar.

The system is a pixel-exact port of a pen.dev design at 1440px. Below that width it collapses to one column with 44px touch targets and no horizontal scroll. Where the build and the pen disagree, the pen is the spec and the code mirrors it (strokes drawn inside the box, line-heights rounded to whole pixels, Bricolage rendered at its 96 optical size at every size).

Surfaces: landing (Persuade: sticky condensing header, rounded hero photo panel, USP marquee, product grids, a lavender brownies panel), menu, product page, cart drawer, 2-section checkout (details, then payment), pay page that varies by payment-method kind (QRIS, bank virtual account, e-wallet), account, and admin (Operate: moss sidebar, white cards, tables).

**Key Characteristics:**
- Moss is the single structural color: primary button, sidebar, strokes, selected states.
- Strokes are inset rings, never layout-affecting borders.
- Three radii only: 12, 20, 999.
- Flat at rest; depth comes from tonal layers (paper, oat, white, mint, tints) and hairlines.
- Display type is tight and heavy; labels are mono.

## Colors

A warm-paper neutral base with one deep green and a rotating confectionery accent set.

### Primary
- **Moss** (`colors.moss`): primary buttons, admin sidebar, all full strokes, active nav text, switch-on state.
- **Moss Deep** (`colors.moss-deep`): primary hover, and text on the white inverse hero button.

### Secondary
- **Mustard** (`colors.mustard`): the highlight. Hero chip fill, cart count badge, cart item-count pill, awaiting-payment status dot. Tint-mustard is its pale badge fill.
- **Mint** (`colors.mint`): selected option tile fill, success/ready/delivery badge fill, secondary text on moss.

### Tertiary
- **Lavender, Salmon, Lime tints** (`colors.tint-lavender`, `colors.tint-salmon`, `colors.tint-lime`): large panel fills (the brownies panel is lavender) and badge fills (baking, failed/expired).
- **Accent set** (`colors.accent-*`): small dots and product-category swatches only (the four hero dots, status dots).
- **Crimson** (`colors.crimson`): errors and invalid input stroke. **Success Green** (`colors.success-green`): paid/completed dot.

### Neutral
- **Paper** (`colors.paper`): page background and theme-color.
- **Oat** (`colors.oat`): cards, chip default fill, USP marquee band, cart footer, hover fills.
- **White**: inputs, admin cards, unselected tiles, text on moss.
- **Ink** (`colors.ink`): body text and the default focus ring. **Muted Ink** (`colors.muted-ink`): helper text, table headers.
- **Strokes**: `stroke-subtle` (cards, tiles, hairlines), `stroke-divider` (summary and timeline dividers), `stroke-input` (form fields). Utilities: `border-subtle`, `border-divider`, `border-input`.

### Named Rules
**The One Structure Color Rule.** Moss carries structure; accents carry only small marks and panel tints. A screen never has two competing saturated fills.
**The Token-First Rule.** Never hard-code a hex that has a token. The one pen-stroke exception pair (`border-divider`, `border-input`) exists precisely because the pen drew them without a variable.
**The Inverse Focus Rule.** Focus ring is ink on light surfaces; any moss or photo container sets `--focus-ring: white`.

## Typography

**Display Font:** Bricolage Grotesque (variable, `opsz` axis, rendered at opsz 96 everywhere via `html`)
**Body Font:** Manrope (variable)
**Label/Mono Font:** IBM Plex Mono, 600 only, normal and italic

**Character:** A chunky, slightly quirky grotesque for voice, a clean humanist sans for reading, and a mono for prices-adjacent labels, chips and table headers.

**Full ramp:** The six named roles below are the core. The pen is laid out per frame, so it also uses intermediate display steps (24–88px, plus the 220/120px 404 numeral), a 17–20px lede/body-large, and 9–12px badge and micro-label sizes. Every one of those steps is in the frontmatter `typography` map and was copied from the pen at 1440. Before adding a new size, pick the nearest existing step.

### Hierarchy
- **Display** (700, 52 / 80 / 112px, line-height 50 / 76 / 106px, tracking -1.5 to -3px): landing hero h1 only, stepping up at sm and lg.
- **Headline** (700, 34 / 44 / 52px, line-height about 1.0-1.05, tracking -1px): page titles, section headings.
- **Title** (600-700, 20-30px, line-height 1.1-1.2): cart title, empty states, order-line names, brand name.
- **Body** (Manrope 400, 16-17px, line-height normal to 26px; 15px for secondary and admin text, 13px for helper/error): paragraphs; keep measure near 560-600px (`max-w-[560px]`/`[600px]`).
- **Label** (Plex Mono 600, 13px chips and badges, 11-12px table headers and sidebar status, tracking 1px where uppercase-free eyebrow-style text exists): chips, stickers, table column headers, cart counts.
- **Button** (Bricolage 600, 15px, tracking 0.5px): all buttons and arrow links.

### Named Rules
**The Whole-Pixel Leading Rule.** Line-height is written in px, the pen's multiplier rounded half-up (14 x 1.3 gives 18px, 15 x 1.5 gives 23px) so box heights add up.
**The Display-Is-Bricolage Rule.** Headings, buttons and brand use `font-display`; never a system display face.

### Pen-mandated exception: eyebrows
The mono uppercase eyebrow above section and page titles ("SOFT COOKIES", "VISIT US", the admin date line, "MY ACCOUNT"; `src/components/content/eyebrow.tsx`, `PageHead eyebrow` in `src/components/admin/ui.tsx`) is drawn in every pen frame. The impeccable craft floor discourages kicker labels, but the owner made the pen binding at 1440 ("UI digenerate dari file pen.dev … harus sama persis"), so they stay exactly where the pen puts them: never add new ones outside the pen, and drop them only on the owner's word.

## Layout

Content sits in a `max-w-[1440px]` centered column. Landing sections run full width inside 12px (mobile) and 24px (sm+) outer gutters; inner section padding is `px-5`/`px-10`/`px-16` stepping up by breakpoint. Vertical rhythm between landing sections is large: `pt-20 pb-16` mobile, `pt-28 pb-24` at lg. Product grids are 2 columns on mobile, 4 at lg (`gap-x-4 gap-y-8`, `lg:gap-6`). Admin uses a fixed 272px sticky sidebar from lg and a moss top bar with a 300px slide-in drawer below it; the main column pads 16/24/48px and stacks cards with 24px gaps. Header: 72px tall on mobile and 100px at md, condensing to 56/64px with a hairline once scrolled; a bottom margin returns the difference so content does not jump.

Touch targets are 44px minimum. Visible controls smaller than that (28px stepper buttons, text links) get an invisible `after:` hit-slop pseudo-element rather than being enlarged. The `lg` breakpoint is the sidebar/column switch; `sm` (640px) and `md` (768px) govern header height and gutters.

### Named Rules
**The Hit-Slop Rule.** Keep the pen's visual size and extend the hit area with `after:absolute after:-inset-*`.

## Elevation & Depth

Flat by default. Depth is tonal: paper under oat under white, mint and tint panels, plus 1px hairlines drawn as inset box-shadows (`inset 0 -1px 0 stroke-subtle`) for row and header separators. The only drop shadow is a soft ink-tinted lift for floating layers (admin dropdowns, search popover, category filter, add-to-cart popover): `0 12px 32px` at 15% ink, with a tighter `0 4px 12px` variant. Overlays (cart drawer, mobile menu) use a 50% ink scrim and no shadow.

### Named Rules
**The Hairline-Not-Border Rule.** Separators are inset shadows or inset rings, so they never change a box's size.
**The Flat-Until-Floating Rule.** Only layers that float above content get a drop shadow.
**The Cutout Exception.** Photographic cookie cutouts (`Cutout` in `src/components/ui/snapshot.tsx`) carry their own `drop-shadow` (`0 10px 12px` at 22% ink) because they sit on top of a panel as objects. They are decorative only (`alt=""`, `aria-hidden`), shown from `lg` up except the menu promo tile, placed on a panel edge or corner and never over an action. Use at most two per screen.

## Shapes

Three radii: 12px for buttons, inputs, tiles and small panels (`rounded-sm`, the pen's `--radius-s`; do not use Tailwind's logical `rounded-s`), 20px for cards and large panels (`rounded-m`), and full pill (999px) for chips, badges, steppers, icon buttons and the logo badge. Full strokes are 1.25-1.5px inset rings (`inset-ring-[1.5px] inset-ring-border`; subtle 1.25px for unselected tiles; 1px for admin cards). Stickers are pills rotated -8deg (the small card/gallery variant, `Sticker size="sm"`, rotates -10deg); photo frames (`Snapshot`) tilt 1.5-3deg with a 20px radius and a 1.5px inset ring; the landing brownies image sits on a -3deg tilted oat plate. Icons are lucide line icons at 18-24px.

## Components

### Buttons
- **Shape:** 12px radius, 16px / 28px padding, Bricolage 600 15px, tracking 0.5px.
- **Primary:** moss fill, white text; hover moss-deep.
- **Secondary:** transparent, ink text, 1.5px moss inset ring; hover oat fill.
- **Inverse:** white fill on moss or photo surfaces; hover oat. On the hero, secondary is recolored white with a white ring and a white 10% hover.
- **Arrow link:** Bricolage 600 15px with a 1.25px moss underline drawn as an inset shadow and a lucide arrow that nudges 2px on hover.
- Disabled: 50% opacity, not-allowed cursor.

### Chips, Stickers, Status Badges
- **Chip:** pill, oat fill, Plex Mono 600 13px, 8/14px padding. Hero chip overrides to mustard.
- **Sticker:** pill, paper fill, 1.25px moss ring, rotated -8deg.
- **Status badge:** pill, tinted fill, 8px dot plus 13px 600 label. Tone map: mustard awaiting payment, mint with green dot paid/completed, lavender baking, mint with teal dot ready for pickup, mint with cobalt dot out for delivery, salmon with crimson dot failed/expired, oat with muted dot new/cancelled/hidden.

### Cards / Containers
- Storefront cards: oat fill, 20px radius, no border. Admin `Card`: white, 20px radius, 1px subtle inset ring.
- Cart drawer: paper body, hairline-separated rows, oat footer; slides in, fades under reduced motion.

### Inputs / Fields
- White fill, 12px radius, 14/16px padding, 16px text, 1.25px `border-input` inset ring. Label is 14px 600 above; helper and error 13px below.
- Focus: ring thickens to 2px moss. Invalid: crimson ring plus `role="alert"` text. Disabled: oat fill.
- Option and payment tiles are real radio inputs: white with a subtle ring; checked becomes mint with a 1.5px moss ring and a filled dot.
- Quantity stepper: pill with 1.25px moss ring, 36px buttons (28px `sm` in the drawer), bold tabular numerals.

### Navigation
- **Site header:** paper, sticky, centered 76px logo badge (48px condensed), 40px circular icon links (menu, search, account, cart) with oat hover; mustard cart-count pill. Menu opens a dialog.
- **Admin sidebar:** moss, 272px, white 15px 600 items with 20px icons; active item flips to a paper pill with moss text; hover white 10%. Store status block at the bottom, mint secondary links.
- **Announcement bar:** static moss strip above the header, white Plex Mono 600 at 12/13px, mustard dot separators, white focus ring; secondary items hide below `md`. No motion.
- **USP marquee:** oat band, two identical halves translated -50% over 55s linear; static grid under reduced motion; pause control present.

### Pay page
One page, content varies by payment-method kind (QR image, virtual-account number with copy button, e-wallet handoff), always with the countdown, order summary, how-to-pay accordion (native `details`) and a change-method form.

### Motion
Durations 150-300ms, `ease-out`, on color, transform and opacity only. Each animation carries its own `motion-reduce:` fallback (fade instead of slide, static row instead of marquee); there is no global reduced-motion kill.

## Do's and Don'ts

### Do:
- **Do** reach for tokens: `bg-primary`, `bg-card`, `text-muted-foreground`, `inset-ring-border`, `rounded-sm|m|pill`.
- **Do** draw strokes as inset rings or inset shadows so sizes match the design.
- **Do** write line-height in whole px and letter-spacing in px.
- **Do** set `[--focus-ring:var(--white)]` on moss and photo containers; use `outline-hidden`, never `outline-none`.
- **Do** use `cn()` (tailwind-merge) so a later class wins; use `Button`/`ButtonLink`/`Chip`/`Field`/`StatusBadge` rather than re-styling.
- **Do** give every new animation a `motion-reduce:` variant.
- **Do** keep prices as `Rp` plus dot thousands and product names in English.

### Don't:
- **Don't** use `border-*` for pen strokes; it resizes the box.
- **Don't** use `rounded-s` (logical corner); the 12px radius is `rounded-sm`.
- **Don't** add a fourth radius or a second saturated structural color.
- **Don't** put drop shadows on resting cards.
- **Don't** hard-code a hex that has a token, or edit `globals.css` casually (Turbopack does not hot-reload it reliably).
- **Don't** shrink a control below 44px of hit area on mobile; add hit-slop instead.
